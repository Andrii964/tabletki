# Tabletki.ua — мобільний застосунок (прототип)

Навчальний проєкт з дисципліни «Людино-машинна взаємодія», ПЗ-24.
Медвідь Д., Свистун А.

## Як запустити
Відкрити `index.html` у браузері. Інтернет не потрібен (крім шрифтів при першому відкритті).

## Як опублікувати на GitHub Pages
1. Скопіювати всі файли в папку репозиторію.
2. Commit → Push.
3. На github.com: Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Через 1-2 хв сайт буде за адресою `https://<нік>.github.io/<репозиторій>/`.

## Як встановити на телефон
Відкрити адресу в Chrome на Android → меню (⋮) → «Встановити застосунок».
Значок зʼявиться на робочому столі, застосунок відкривається без адресного рядка і працює офлайн.

## Склад
| Файл | Призначення |

| `index.html` | каркас застосунку |

| `sw.js`, `manifest.webmanifest` | офлайн-режим і встановлення на телефон |

## Сценарії для тестування
1. Знайти ліки через пошук і забронювати в аптеці.
2. Замовити повторно з нагадування в «Моїй аптечці».
3. Запитати ШІ-помічника про інструкцію (перша спроба навмисно дає помилку).
4. Оформити доставку кур'єром з вибором часу.
5. Знайти дешевший аналог за діючою речовиною.
6. Підібрати препарат через каталог категорій.
7. Додати ліки в аптечку й налаштувати схему прийому.
8. Повторити замовлення з історії.

Перед кожною сесією тестування: Профіль → «Очистити дані застосунку».
